# AISIX AI Gateway Integration

The **AISIX AI Gateway** integration provides end-to-end observability for LLM request traffic, token consumption, model performance, cache efficiency, policy enforcement, and upstream deployment health.

## Key Capabilities

- **Gateway Overview**: Track LLM request throughput, success rates, in-flight connections, and configuration reload status.
- **Model Performance**: Monitor P50/P95/P99 end-to-end latency and streaming Time To First Token (TTFT) across providers and models.
- **Token & Policy Activity**: Analyze input/output token usage, prompt cache hit ratios, rate-limiting rejections, and guardrail enforcement.
- **Routing & Delivery**: Observe upstream deployment health, fallback attempt success rates, and dropped usage events.
